## Usage

```tsx
import type { DocJSON } from '@zeroxsolutions/editor-core/document/core/index';

import { tableOfContents } from '@/components/editor/document/features/table-of-contents';
import { standardKit } from '@/components/editor/document/features/standard';
import { Editor } from '@/components/editor/document/react';
```

```tsx
const features = [standardKit(), tableOfContents()];

function NotesEditor({ content }: { content: DocJSON }) {
  return <Editor features={features} content={content} />;
}
```

`tableOfContents` adds the `tableOfContents` block: the document's headings of level 1 to 3, a toggle heading's
included, each a link that scrolls to its heading. Its slash item is "Table of contents". The list is read from
the document wherever it is drawn, so it follows a heading that is renamed, moved or deleted. `words` names the
list for a screen reader and sets the line the editor shows while the document has no heading.

A block's HTML is written from the block alone, so HTML and Markdown keep the block's place as an empty `nav`,
which reads back as the block.

The `Viewer` draws the same block, with the same feature in its `features`, wherever a stored document is only read.
