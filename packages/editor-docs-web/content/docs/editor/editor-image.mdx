## Usage

```tsx
import type { DocJSON, IEditor } from '@zeroxsolutions/editor-core/document/core/index';

import { image } from '@/components/editor/document/features/image';
import { standardKit } from '@/components/editor/document/features/standard';
import { Editor } from '@/components/editor/document/react';
```

```tsx
const features = [standardKit(), image()];

function NotesEditor({ content }: { content: DocJSON }) {
  return <Editor features={features} content={content} />;
}
```

`image` adds the `image` block, with the attributes `src`, `alt`, `title` and `width`. Selecting it opens an Edit popover for the alt text and the width. Its slash item is "Image" and its command `insertImage` takes a `src` and an optional `alt` and `title`.

`words` sets the popover's button and fields and what an image with no address shows, over the English of
`DEFAULT_IMAGE_WORDS`. Pass a function to read them each time the block draws, so a change of language shows
without rebuilding the editor:

```tsx
const features = [standardKit(), image({ words: { edit: 'Bearbeiten', empty: 'Leeres Bild' } })];
```

Run the command on the editor that `Editor` hands to `onReady`, as [Document Editor](/docs/editor/document-editor) shows:

```tsx
function insert(editor: IEditor) {
  editor.run('insertImage', { src: '/lantern.jpg', alt: 'A red paper lantern' });
}
```

### Uploads

Give `image` your upload and the Edit popover gets an Upload tab beside the address, and an image file pasted or
dropped into the editor becomes an image block that uploads it:

```tsx
const features = [standardKit(), image({ upload, maxBytes: 10 * 1024 * 1024 })];
```

The block draws the picked file faint, with its progress and a cancel, until your address lands as `src`.
[Editor Uploads](/docs/editor/editor-uploads) describes `upload`, `accept`, `maxBytes` and `messages`.

The `Viewer` draws the same block, with the same feature in its `features`, wherever a stored document is only read.
