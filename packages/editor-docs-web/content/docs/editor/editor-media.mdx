## Usage

```tsx
import type { DocJSON } from '@zeroxsolutions/editor-core/document/core/index';

import { media } from '@/components/editor/document/features/media';
import { standardKit } from '@/components/editor/document/features/standard';
import { Editor } from '@/components/editor/document/react';
```

```tsx
const features = [standardKit(), media()];

function NotesEditor({ content }: { content: DocJSON }) {
  return <Editor features={features} content={content} />;
}
```

`media` adds the `media` block: a video or audio player with its controls, and a caption under it. Its slash
items are "Video" and "Audio", which set `kind`. The author pastes the file's link into the empty block and
writes the caption under the player. A video's `poster` is the image it shows before it plays. Only a web
address is loaded.

HTML writes a `figure` holding a `video` or `audio` element with `controls`, and the caption as its
`figcaption`. Markdown writes the same HTML on one line.

The `Viewer` draws the same block, with the same feature in its `features`, wherever a stored document is only read.
