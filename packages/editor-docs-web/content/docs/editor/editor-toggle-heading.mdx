## Usage

```tsx
import type { DocJSON } from '@zeroxsolutions/editor-core/document/core/index';

import { toggleHeading } from '@/components/editor/document/features/toggle-heading';
import { standardKit } from '@/components/editor/document/features/standard';
import { Editor } from '@/components/editor/document/react';
```

```tsx
const features = [standardKit(), toggleHeading()];

function NotesEditor({ content }: { content: DocJSON }) {
  return <Editor features={features} content={content} />;
}
```

`toggleHeading` adds the `toggleHeading` block: a heading of level 1 to 3 that folds away the blocks under it.
Its slash items are "Toggle heading 1" to "Toggle heading 3", and its command `insertToggleHeading` takes the
`level`. `open` is whether it is unfolded. A table of contents lists the heading as it lists any other.

HTML writes `<details data-toggle-heading>` with the heading in its `summary` and the folded blocks after it,
which the Toggle's `details` leaves alone. Markdown writes the opening and the summary as HTML, the heading as its
plain text, and the folded blocks as Markdown, and reads them back together.

The `Viewer` draws the same block, with the same feature in its `features`, wherever a stored document is only read.
