## Usage

```tsx
import type { DocJSON } from '@zeroxsolutions/editor-core/document/core/index';

import { callout, standardKit, toggle } from '@/components/editor/document/features';
import { Editor } from '@/components/editor/document/react';
```

```tsx
const features = [standardKit(), callout(), toggle()];

function NotesEditor({ content }: { content: DocJSON }) {
  return <Editor features={features} content={content} />;
}
```

The barrel exports `standardKit`, `callout`, `toggle`, `link`, `image`, `table`, `codeBlock`, `mermaid`, `math`, `mention`, `embed`, `toggleHeading`, `button`, `columns`, `card`, `bookmark`, `file`, `media` and `tableOfContents`, each the one function its own page shows. `card` takes the card's shared definition, `card` from `@zeroxsolutions/editor-core/blocks/index`, as [Editor Card](/docs/editor/editor-card) shows. Installing it installs every feature, with KaTeX and Mermaid behind two of them; to keep a project to the blocks it draws, install the feature items one by one and import each from its own folder.
