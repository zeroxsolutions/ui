## Usage

```tsx
import type { DocJSON } from '@zeroxsolutions/editor-core/document/core/index';
import { card as cardBlock } from '@zeroxsolutions/editor-core/blocks/index';

import { card } from '@/components/editor/document/features/card';
import { standardKit } from '@/components/editor/document/features/standard';
import { Editor } from '@/components/editor/document/react';
```

```tsx
const features = [standardKit(), card(cardBlock)];

function NotesEditor({ content }: { content: DocJSON }) {
  return <Editor features={features} content={content} />;
}
```

`card` adds the `card` block: an image over a title, a text and a link button. It takes the card's shared
definition, `card` from `@zeroxsolutions/editor-core/blocks/index`, which is the email editor's card too, so a
card reads the same in a document and in an email. Its slash item is "Card". The author pastes the image's link
into the empty card, then writes the alt text, the title, the text, the button's label and the button's link in
place. `words` renames those fields. Give `card` your upload, as `card(cardBlock, { upload })`, and the image's
popover gets an Upload tab beside the address; see [Editor Uploads](/docs/editor/editor-uploads).

The button is drawn only with both a label and a web or mail link, and the image only from a web address. HTML
writes the card as a `figure` with its image, a `figcaption` holding the title, the text and the button, and the
card's fields in `data-block-attrs`, so it reads back whole. Markdown writes the same HTML on one line.

The `Viewer` draws the same block, with the same feature in its `features`, wherever a stored document is only read.
