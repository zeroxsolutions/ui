## Usage

```tsx
import type { DocJSON } from '@zeroxsolutions/editor-core/document/core/index';

import { columns } from '@/components/editor/document/features/columns';
import { standardKit } from '@/components/editor/document/features/standard';
import { Editor } from '@/components/editor/document/react';
```

```tsx
const features = [standardKit(), columns()];

function NotesEditor({ content }: { content: DocJSON }) {
  return <Editor features={features} content={content} />;
}
```

`columns` adds the `columns` block, which holds `column` blocks, each holding any blocks. Its slash item is
"Columns", and its command `insertColumns` takes an optional `count` from 2 to 4, 2 by default. `ratio` weighs the
columns against each other, as whole numbers from 1 to 12, and `insertColumns` writes equal weights. Below 40rem the
columns stack.

HTML keeps the columns whole. Markdown has no columns, so it writes each column's blocks in order, and they read
back as blocks in a row. `columnContent` narrows what a column holds; the email editor's holds no columns.

The `Viewer` draws the same block, with the same feature in its `features`, wherever a stored document is only read.
