## Installation

<InstallCommand name="avatar" />

The CLI writes `components/ui/avatar.tsx`, installs [Icon](/native/components/nativewind/icon),
[Text](/native/components/nativewind/text) and Utils, and adds
`@rn-primitives/avatar`.

## Usage

```tsx
import {
  Avatar,
  AvatarBadge,
  AvatarFallback,
  AvatarGroup,
  AvatarGroupCount,
  AvatarImage,
} from '@/components/ui/avatar';
import { Text } from '@/components/ui/text';
```

```tsx
<Avatar alt="Ada Lovelace">
  <AvatarImage source={{ uri: 'https://example.com/ada.png' }} />
  <AvatarFallback>
    <Text>AL</Text>
  </AvatarFallback>
</Avatar>
```

### Badge

```tsx
<Avatar alt="Ada Lovelace, online">
  <AvatarImage source={{ uri: 'https://example.com/ada.png' }} />
  <AvatarFallback>
    <Text>AL</Text>
  </AvatarFallback>
  <AvatarBadge className="bg-success" />
</Avatar>
```

### Group

```tsx
<AvatarGroup>
  <Avatar alt="Ada Lovelace">
    <AvatarFallback>
      <Text>AL</Text>
    </AvatarFallback>
  </Avatar>
  <Avatar alt="Grace Hopper">
    <AvatarFallback>
      <Text>GH</Text>
    </AvatarFallback>
  </Avatar>
  <AvatarGroupCount>
    <Text>+3</Text>
  </AvatarGroupCount>
</AvatarGroup>
```

## API reference

### Avatar

Takes every prop of the `@rn-primitives/avatar` root, plus:

| Prop   | Type                        | Default     |
| ------ | --------------------------- | ----------- |
| `alt`  | `string`                    | required    |
| `size` | `'default' \| 'sm' \| 'lg'` | `'default'` |

`alt` names the avatar. The image carries it, and so does the fallback while it stands in. `sm` draws 24px,
`lg` 40px, and the default is 32px.

### AvatarImage

Takes every prop of the `@rn-primitives/avatar` image. It draws nothing if it fails to load.

### AvatarFallback

Shows until the image has loaded, and for good when there is no image or it failed. Its child is usually
initials as a Text. It is announced as an image named by the avatar's `alt`.

### AvatarBadge

Takes every prop of React Native's `View`. A dot on the avatar's bottom right corner, in the primary colour with a
2px edge in the background colour; give it another colour with `className`. It grows with the avatar, and an
[Icon](/native/components/nativewind/icon) inside takes 8px, except on the `sm` avatar, whose dot draws none. A
screen reader skips it, so say what it marks in the avatar's `alt`.

### AvatarGroup

Takes every prop of `View`. A row of its Avatars, each overlapping the one before by 8px and edged in the
background colour, with an AvatarGroupCount at the end. The avatars and the count are its direct children.

### AvatarGroupCount

Takes every prop of `View`. The muted circle at the end of the group, as large as the group's avatars, holding how
many more there are as a Text, or an Icon.

## Differences from upstream

- The web draws the badge's edge and a grouped avatar's as a 2px ring outside the circle, which a device cannot
  draw. The badge draws it as a border on a dot 4px larger, so the dot inside is upstream's size; a grouped avatar
  and the count draw it as a border inside their edge, so their picture is 4px smaller than upstream's.
