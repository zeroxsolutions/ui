## Installation

<InstallCommand name="icon-label" />

The CLI writes `components/general/icon-label.tsx`, installs [Icon](/native/components/nativewind/icon),
[Text](/native/components/nativewind/text) and Utils, and adds `@rn-primitives/label`.

## Usage

```tsx
import { IconLabel } from '@/components/general/icon-label';
```

```tsx
const input = useRef<TextInputInstance>(null);

<IconLabel aria-label="Filter" nativeID="filter" onPress={() => input.current?.focus()}>
  <Icon as={Search} />
</IconLabel>
<Input ref={input} aria-label="Filter" aria-labelledby="filter" placeholder="Filter..." />
```

Use it to stand in for a field's own text label in a dense panel. Compose a
[Tooltip](/native/components/nativewind/tooltip) around it, with `asChild` on the trigger, to show the words when
it is pressed; it then opens the tooltip rather than focusing the input. For a glyph that carries no field of its
own, such as a model ability, use [Icon media](/native/components/nativewind/icon-media) instead.

## API reference

### IconLabel

Takes every prop of `@rn-primitives/label`'s `Root`, a `Pressable`, plus:

| Prop         | Type     | Default  |
| ------------ | -------- | -------- |
| `aria-label` | `string` | required |
| `nativeID`   | `string` | -        |

`aria-label` holds the words the icon stands in for, which a screen reader reads. An input that names
`nativeID` in `aria-labelledby` takes the label's name on Android; iOS does not read `aria-labelledby`, so give
the input the same words in its own `aria-label`. Pressing the label runs its `onPress`, which you point at the
input's `focus()`. An Icon inside it with no `size-*` class of its own is drawn at `size-3`, in the muted
foreground.

## Differences from the web

- The web's `htmlFor` is dropped: React Native has no label-to-input link, so `nativeID` and `onPress` stand in
  for it, as on [Label](/native/components/nativewind/label).
- The web's visually hidden `sr-only` text is dropped, since a device has no such class; the words go in the
  required `aria-label`.
