---
title: Input OTP
description: A one-time code entered in a row of slots, one character each, with a caret on the next slot.
---

## Installation

```bash
pnpm dlx shadcn@latest add @zui/input-otp
```

The CLI writes `components/ui/input-otp.tsx`, installs [Text](/docs/native/text), [Icon](/docs/native/icon) and
Utils, and adds `lucide-react-native`.

## Usage

```tsx
import { useState } from 'react';

import { InputOTP, InputOTPGroup, InputOTPSeparator, InputOTPSlot } from '@/components/ui/input-otp';
```

```tsx
const [code, setCode] = useState('');

<InputOTP maxLength={6} value={code} onChange={setCode} onComplete={verify} aria-label="Verification code">
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>;
```

## API reference

### InputOTP

Takes every prop of React Native's `TextInput` except `defaultValue`, `onChange`, `onChangeText` and `maxLength`,
which it redefines, plus:

| Prop                 | Type                         | Default                           |
| -------------------- | ---------------------------- | --------------------------------- |
| `maxLength`          | `number`                     | required                          |
| `value`              | `string`                     | none                              |
| `defaultValue`       | `string`                     | `''`                              |
| `onChange`           | `(value: string) => void`    | none                              |
| `onComplete`         | `(value: string) => void`    | none                              |
| `pattern`            | `string \| RegExp`           | `REGEXP_ONLY_DIGITS`              |
| `pasteTransformer`   | `(pasted: string) => string` | removes spaces and dashes         |
| `containerClassName` | `string`                     | none                              |
| `aria-invalid`       | `boolean`                    | none                              |
| `aria-label`         | `string`                     | required, or `accessibilityLabel` |

One text field, hidden under the slots, takes the keystrokes, a paste and the code the OS offers from a text
message. A screen reader meets one field, named with `aria-label` or `accessibilityLabel`, one of which the type
requires, and the slots are hidden from it. The field
opens the number pad unless given another `keyboardType`.

Leave `value` out to let the field hold the code, or pass `value` and `onChange` to control it. `onChange` runs
after each change the `pattern` accepts and `onComplete` once the code is `maxLength` long. A change that does
not match `pattern` is refused. The patterns the file exports are `REGEXP_ONLY_DIGITS`, `REGEXP_ONLY_CHARS`
and `REGEXP_ONLY_DIGITS_AND_CHARS`.

`aria-invalid` draws every slot with the destructive border. React Native does not announce it, so carry the
error in `accessibilityHint` or in a Text the user can reach. `editable={false}` dims it and announces it
disabled. A `style` goes to the hidden field.

### InputOTPGroup

Takes every prop of a React Native `View`.

Draws its slots joined and rounded on the outside. The slots are its direct children.

### InputOTPSlot

Takes every prop of a React Native `View`, plus:

| Prop            | Type      | Default  |
| --------------- | --------- | -------- |
| `index`         | `number`  | required |
| `aria-invalid`  | `boolean` | none     |
| `textClassName` | `string`  | none     |

Shows the character of the code at `index`, counted from 0. The slot the next character goes in takes the
focus border and a caret while the code holds focus. `aria-invalid` on a slot overrides the code's. `textClassName` sets the classes of the character and wins over
the style's text size.

### InputOTPSeparator

Takes every prop of a React Native `View`.

A dash between two groups, hidden from screen readers.
