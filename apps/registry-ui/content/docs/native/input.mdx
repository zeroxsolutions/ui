title: Input

---

## Installation

```bash
pnpm dlx shadcn@latest add @zui/input
```

The CLI writes `components/ui/input.tsx` and installs Utils. The file is the engine's own version, so a
NativeWind app and a Uniwind app each get theirs.

## Usage

```tsx
import { Input } from '@/components/ui/input';
```

```tsx
<Input placeholder="you@example.com" keyboardType="email-address" aria-labelledby="email-label" />
```

Name it with a [Label](/docs/native/label) through `aria-labelledby`.

## API reference

### Input

Takes every prop React Native's `TextInput` takes, plus:

| Prop           | Type      | Default |
| -------------- | --------- | ------- |
| `aria-invalid` | `boolean` | none    |

The field takes the focus border while it holds focus. `aria-invalid` draws the destructive border and
announces the field as invalid. `editable={false}` dims it and announces it disabled.

The placeholder colour differs by engine. The NativeWind file draws it through the `placeholder:` variant. The
Uniwind file draws it through `placeholderTextColorClassName`, which takes an `accent-` class.
