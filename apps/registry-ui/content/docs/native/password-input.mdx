---
title: Password input
description: A password field whose toggle shows or hides the password.
---

## Installation

```bash
pnpm dlx shadcn@latest add @zui/password-input
```

The CLI writes `components/data-entry/password-input.tsx`, installs [Input group](/docs/native/input-group) and
[Icon](/docs/native/icon) with the items they need, and adds `lucide-react-native`.

## Usage

```tsx
import { PasswordInput, PasswordInputInput, PasswordInputToggle } from '@/components/data-entry/password-input';
import { InputGroupAddon } from '@/components/ui/input-group';
```

```tsx
<PasswordInput>
  <PasswordInputInput aria-label="Password" autoComplete="current-password" />
  <InputGroupAddon align="inline-end">
    <PasswordInputToggle />
  </InputGroupAddon>
</PasswordInput>
```

The toggle does not move focus, so the field keeps it and the keyboard stays up. Inside a `ScrollView`, set
`keyboardShouldPersistTaps="handled"` on it, or the first tap on the toggle only dismisses the keyboard.

## API reference

### PasswordInput

Takes every prop of [InputGroup](/docs/native/input-group), and holds whether the password shows. Its
children are a PasswordInputInput and InputGroupAddons, one of them holding the PasswordInputToggle.

### PasswordInputInput

Takes every prop of [InputGroupInput](/docs/native/input-group) except `secureTextEntry`, which
the root sets.

It types with `autoCapitalize="none"` and `autoCorrect={false}`, so a shown password is not changed as it is
typed; pass either to override it. Name the field with `aria-label`, and pass `autoComplete="current-password"`
for a sign-in or `"new-password"` for a new account, so the platform's password manager fills or suggests one.

### PasswordInputToggle

Takes every prop of [InputGroupButton](/docs/native/input-group) except `size` and `children`,
plus:

| Prop        | Type     | Default           |
| ----------- | -------- | ----------------- |
| `showLabel` | `string` | `'Show password'` |
| `hideLabel` | `string` | `'Hide password'` |

An `icon-xs` button, ghost unless `variant` says otherwise, announced as a button and named `showLabel` while the
password is hidden and `hideLabel` while it shows. Pass both translated. It draws an eye, and a struck eye while the password shows.
An `onPress` runs before the toggle.
