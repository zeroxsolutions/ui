---
title: Native
description: React Native items for iOS and Android, drawn in shadcn's Vega or Nova style, for NativeWind or Uniwind.
---

zui native publishes React Native items for iOS and Android apps, installed with the shadcn CLI like the web
items. Each item draws shadcn's Vega or Nova style with its neutral colours, and is published once per styling
engine and style:

| Engine       | Style | `style` in `components.json` | Items served from                                                    |
| ------------ | ----- | ---------------------------- | -------------------------------------------------------------------- |
| NativeWind 4 | Vega  | `nativewind-vega`            | `https://ui.zeroxsolutions.com/r/styles/nativewind-vega/<name>.json` |
| NativeWind 4 | Nova  | `nativewind-nova`            | `https://ui.zeroxsolutions.com/r/styles/nativewind-nova/<name>.json` |
| Uniwind      | Vega  | `uniwind-vega`               | `https://ui.zeroxsolutions.com/r/styles/uniwind-vega/<name>.json`    |
| Uniwind      | Nova  | `uniwind-nova`               | `https://ui.zeroxsolutions.com/r/styles/uniwind-nova/<name>.json`    |

The CLI picks the path from the app's `style`, so an app names its engine and style once, in `components.json`, as
[Installation](/docs/native/installation) shows.

## Items

- [Theme](/docs/native/theme): the colours, radius and Geist font families, and the map that loads the fonts.
- [Text](/docs/native/text): text that takes its container's text classes.
- [Icon](/docs/native/icon): a lucide icon sized and coloured by classes.
- [Button](/docs/native/button): a pressable control in the style's variants and sizes.
- [Toggle](/docs/native/toggle): a two-state button, announced as selected while pressed.
- [Toggle group](/docs/native/toggle-group): toggles of which one or several are pressed.
- [Label](/docs/native/label): the text that names a field.
- [Input](/docs/native/input): a single-line text field.
- [Input group](/docs/native/input-group): an input with text, icons or buttons beside it.
- [Input OTP](/docs/native/input-otp): a one-time code in a row of slots.
- [Password input](/docs/native/password-input): a password field whose toggle shows or hides the password.
- [Password strength](/docs/native/password-strength): a meter and checklist for how strong a password is.
- [Code input](/docs/native/code-input): a six-character one-time code in one group of slots or two.
- [Textarea](/docs/native/textarea): a multiline text field.
- [Checkbox](/docs/native/checkbox): a box that is checked or not.
- [Radio group](/docs/native/radio-group): a set of choices of which one is selected.
- [Switch](/docs/native/switch): an on/off control.
- [Avatar](/docs/native/avatar): a round picture with a fallback.
- [Badge](/docs/native/badge): a small pill for a status or a count.
- [Card](/docs/native/card): a surface that groups related content.
- [Progress](/docs/native/progress): a bar showing how far a task has got.
- [Separator](/docs/native/separator): a rule between groups of content.
- [Spinner](/docs/native/spinner): a circle that turns while something loads.
- [Unsaved changes toolbar](/docs/native/unsaved-changes-toolbar): a floating bar with Reset and Save while a form has unsaved changes.
- [Skeleton](/docs/native/skeleton): a placeholder block for loading content.
- [Tabs](/docs/native/tabs): panels switched by a row of triggers.

Each component also installs `utils`, which gives it `cn`.

These pages show no live preview, because the items render through React Native and this site does not run it.

## macOS and Windows

zui native targets iOS and Android only. A macOS or Windows app uses the [web items](/docs/components) through
Electron.
