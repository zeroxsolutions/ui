---
title: Password Strength
description: How strong a password is, as a three-step meter announced when it changes, and which of its requirements it meets, in a small card.
---

## Installation

```bash
pnpm dlx shadcn@latest add @zui/password-strength
```

The CLI writes `components/feedback/password-strength.tsx`, installs [Card](/docs/native/card),
[Progress](/docs/native/progress), [Text](/docs/native/text) and [Icon](/docs/native/icon) with the items they need,
and adds `lucide-react-native`.

## Usage

```tsx
import {
  PasswordStrength,
  PasswordStrengthMeter,
  PasswordStrengthRequirement,
  PasswordStrengthRequirements,
} from '@/components/feedback/password-strength';
```

```tsx
<PasswordStrength strength="fair">
  <PasswordStrengthMeter valueText="Fair">Password strength</PasswordStrengthMeter>
  <PasswordStrengthRequirements>
    <PasswordStrengthRequirement met>At least 15 characters</PasswordStrengthRequirement>
    <PasswordStrengthRequirement>Not your name or email</PasswordStrengthRequirement>
  </PasswordStrengthRequirements>
</PasswordStrength>
```

Place it under a new password field, such as a [Password Input](/docs/native/password-input). The caller rates the
password and writes every word. NIST SP 800-63B rev 4 asks a verifier to check a password's length and to refuse one
that is commonly used or contains the person's own data, and not to require a mix of character classes, so the
requirements name those checks and nothing like "one uppercase letter".

## Composition

```text
PasswordStrength
|-- PasswordStrengthMeter
`-- PasswordStrengthRequirements
    `-- PasswordStrengthRequirement
```

## API reference

### PasswordStrength

Takes every prop of [Card](/docs/native/card), small unless `size` says otherwise, plus:

| Prop       | Type                           |
| ---------- | ------------------------------ |
| `strength` | `'weak' \| 'fair' \| 'strong'` |

### PasswordStrengthMeter

Takes every prop of [CardContent](/docs/native/card) except `children`, plus:

| Prop        | Type     | Description                                                       |
| ----------- | -------- | ----------------------------------------------------------------- |
| `children`  | `string` | The meter's name, shown above the bar and what the bar is called. |
| `valueText` | `string` | The strength in words, shown beside the name.                     |

The bar is a [Progress](/docs/native/progress) filled a third for `weak`, two thirds for `fair` and full for
`strong`. `valueText` is the bar's value text and sits in a text with `accessibilityLiveRegion="polite"`. When it
changes after the first render it is also passed to `AccessibilityInfo.announceForAccessibility`; the first value is
not announced.

### PasswordStrengthRequirements

Takes every prop of [CardContent](/docs/native/card). Its children are the requirements.

### PasswordStrengthRequirement

Takes every prop of `View` except `children`, plus:

| Prop         | Type      | Default     |
| ------------ | --------- | ----------- |
| `children`   | `string`  |             |
| `met`        | `boolean` | `false`     |
| `metLabel`   | `string`  | `'Met'`     |
| `unmetLabel` | `string`  | `'Not met'` |

`met` draws a circle-check and foreground text; otherwise a circle and muted text. The requirement is one element
for a screen reader whose value text is `metLabel` or `unmetLabel`, so the state is read with the requirement. Pass
both in the app's language.
