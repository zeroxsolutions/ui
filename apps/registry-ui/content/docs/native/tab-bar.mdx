---
title: Tab Bar
description: A bar of top-level destinations at one edge of the screen, a tablist of pressable tab items with an indicator, an icon, a label and a count badge.
---

## Installation

```bash
pnpm dlx shadcn@latest add @zui/tab-bar
```

The CLI writes `components/navigation/tab-bar.tsx` and installs [Badge](/docs/native/badge),
[Icon](/docs/native/icon), [Text](/docs/native/text) and Utils.

## Usage

```tsx
import { House, Inbox } from 'lucide-react-native';

import {
  TabBar,
  TabBarBadge,
  TabBarIcon,
  TabBarIndicator,
  TabBarItem,
  TabBarLabel,
} from '@/components/navigation/tab-bar';
import { Icon } from '@/components/ui/icon';
```

```tsx
<TabBar accessibilityLabel="Main" labels="selected">
  <TabBarItem active={route === 'home'} onPress={() => navigate('home')}>
    <TabBarIndicator>
      <TabBarIcon>
        <Icon as={House} />
      </TabBarIcon>
    </TabBarIndicator>
    <TabBarLabel>Home</TabBarLabel>
  </TabBarItem>
  <TabBarItem active={route === 'inbox'} onPress={() => navigate('inbox')}>
    <TabBarIndicator>
      <TabBarIcon>
        <Icon as={Inbox} />
      </TabBarIcon>
      <TabBarBadge countLabel="unread">3</TabBarBadge>
    </TabBarIndicator>
    <TabBarLabel>Inbox</TabBarLabel>
  </TabBarItem>
</TabBar>
```

The bar is absolutely positioned, so render it inside a parent that fills the screen. It does not handle safe areas:
your app pads it for the home indicator. It draws no blur, so `translucent` is a 70% background. Each item calls
`onPress`, where you navigate and set `active` on the destination now shown.

## Composition

```text
TabBar
`-- TabBarItem
    |-- TabBarIndicator
    |   |-- TabBarIcon
    |   `-- TabBarBadge
    `-- TabBarLabel
```

## API reference

### TabBar

Takes every prop of `View`, plus:

| Prop                 | Type                                     | Default         |
| -------------------- | ---------------------------------------- | --------------- |
| `accessibilityLabel` | `string` (required)                      |                 |
| `side`               | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'`      |
| `labels`             | `'always' \| 'selected' \| 'none'`       | `'always'`      |
| `surface`            | `'translucent' \| 'solid'`               | `'translucent'` |
| `shape`              | `'attached' \| 'floating'`               | `'attached'`    |

It has the `tablist` role, named by `accessibilityLabel`. Top and bottom lay the items in a row, left and right in a
column. `attached` runs edge to edge, and `floating` is a `rounded-full` pill 16px from the edges; floating on the left
or right sits 16px from the top corner and is as tall as its items, so place it with `className`.

### TabBarItem

Takes every prop of `Pressable`, plus:

| Prop     | Type      | Default |
| -------- | --------- | ------- |
| `active` | `boolean` | `false` |

It has the `tab` role and is announced selected only while `active`. Its name is its `TabBarLabel`. Pass
`accessibilityLabel` to name it otherwise, such as when `labels` hides the label. A `TabBarBadge` inside it becomes its
`accessibilityHint`, unless you pass one.

### TabBarIndicator

Takes every prop of `View`. The pill behind the icon: tinted while the item is active, and muted while the item is
pressed.

### TabBarIcon

Takes every prop of `View`. It holds an [Icon](/docs/native/icon) at 20px in the item's colour, and a screen reader
skips it.

### TabBarBadge

Takes every prop of [Badge](/docs/native/badge) except `variant` and `children`, plus:

| Prop         | Type               | Default |
| ------------ | ------------------ | ------- |
| `children`   | `string \| number` |         |
| `countLabel` | `string`           | `'new'` |

A destructive badge at the indicator's top right. A screen reader skips it, and the item's hint is the count and
`countLabel`, so `3` is heard as "3 new". Both are words a person hears, so your app translates them.

### TabBarLabel

Takes every prop of [Text](/docs/native/text). It is `text-xs`, primary on the active item and muted on the others.
Where `labels` hides it, it stays in the item, transparent and out of the layout, so it still names the item.
