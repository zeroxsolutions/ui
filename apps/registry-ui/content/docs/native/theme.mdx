## Installation

```bash
pnpm dlx shadcn@latest add @zui/theme
```

Add it once, before any component. No component installs it, and adding it again writes its tokens back over
any you edited.

## What it writes

Both engines get `lib/fonts.ts`, which exports `zuiFonts`, and the packages `expo-font` and
`@expo-google-fonts/geist`. The tokens go where the engine reads them:

## Tokens

The colours are shadcn's neutral theme: `background`, `foreground`, `card`, `popover`, `primary`, `secondary`,
`muted` and `accent`, each with its `-foreground`, then `destructive`, `border`, `input`, `ring`, `chart-1`
to `chart-5` and the `sidebar` set. `success` and `warning`, with their `-foreground`, take the values the
web items use. `--radius` is `0.625rem`, so `rounded-md` is 8 points.

## Fonts

| Class                | Family              |
| -------------------- | ------------------- |
| `font-sans`          | `Geist_400Regular`  |
| `font-sans-medium`   | `Geist_500Medium`   |
| `font-sans-semibold` | `Geist_600SemiBold` |
| `font-sans-bold`     | `Geist_700Bold`     |

Each weight is its own family, because React Native picks a custom font by its family name. `zuiFonts` maps
each family to its file; load it with `useFonts` before the first render, as
[Installation](/docs/native/installation#load-the-fonts) shows. Without the theme, `font-sans` names no Geist family
and Text draws in the system font, with no error.

```tsx
import { zuiFonts } from '@/lib/fonts';
```
