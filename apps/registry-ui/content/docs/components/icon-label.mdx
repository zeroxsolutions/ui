## Usage

```tsx
import { IconLabel } from '@/components/general/icon-label';
```

```tsx
<Tooltip>
  <TooltipTrigger render={<IconLabel htmlFor="rotation" />}>
    <RotateCw aria-hidden />
    <span className="sr-only">Rotation</span>
  </TooltipTrigger>
  <TooltipContent>Rotation</TooltipContent>
</Tooltip>
<Input id="rotation" type="number" />
```

Use it to stand in for a field's own text label in a dense panel. For a glyph that carries no field of
its own, such as a model ability, use [Icon Media](/docs/components/icon-media) instead.

## API reference

### IconLabel

Renders a `label` and takes every prop a `label` takes. An svg child with no `size-*` class of its own
is drawn at `size-3`. It sets `data-slot="icon-label"`.
