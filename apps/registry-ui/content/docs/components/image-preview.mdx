## Usage

```tsx
import { ImagePreview, ImagePreviewImage } from '@/components/data-display/image-preview';
```

```tsx
<ImagePreview>
  <ImagePreviewImage src={src} alt="Logo" />
</ImagePreview>
```

It fills the space it is given, so size its wrapper rather than the frame itself. For a font file's specimen
instead of an image, use Font Preview.

## API reference

### ImagePreview

Renders a `div` and takes every prop a `div` takes. It sets `data-slot="image-preview"`.

### ImagePreviewImage

Renders an `img` and takes every prop an `img` takes. It defaults `alt` to empty, since the image usually sits
decoratively over the checkerboard; give it real text when the image conveys information. It sets
`data-slot="image-preview-image"`.
