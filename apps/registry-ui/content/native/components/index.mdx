---
title: Components
description: The React Native items, each published for NativeWind and Uniwind in the Vega and Nova styles.
---

| Item                                                                             | What it is                                                                     |
| -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [Theme](/native/components/nativewind/theme)                                     | The colours, radius and Geist font families, and the map that loads the fonts. |
| [Text](/native/components/nativewind/text)                                       | Text that takes its container's text classes.                                  |
| [Icon](/native/components/nativewind/icon)                                       | A lucide icon sized and coloured by classes.                                   |
| [Button](/native/components/nativewind/button)                                   | A pressable control in the style's variants and sizes.                         |
| [Toggle](/native/components/nativewind/toggle)                                   | A two-state button, announced as selected while pressed.                       |
| [Toggle group](/native/components/nativewind/toggle-group)                       | Toggles of which one or several are pressed.                                   |
| [Label](/native/components/nativewind/label)                                     | The text that names a field.                                                   |
| [Input](/native/components/nativewind/input)                                     | A single-line text field.                                                      |
| [Input group](/native/components/nativewind/input-group)                         | An input with text, icons or buttons beside it.                                |
| [Input OTP](/native/components/nativewind/input-otp)                             | A one-time code in a row of slots.                                             |
| [Password input](/native/components/nativewind/password-input)                   | A password field whose toggle shows or hides the password.                     |
| [Password strength](/native/components/nativewind/password-strength)             | A meter and checklist for how strong a password is.                            |
| [Code input](/native/components/nativewind/code-input)                           | A six-character one-time code in one group of slots or two.                    |
| [Textarea](/native/components/nativewind/textarea)                               | A multiline text field.                                                        |
| [Checkbox](/native/components/nativewind/checkbox)                               | A box that is checked or not.                                                  |
| [Radio group](/native/components/nativewind/radio-group)                         | A set of choices of which one is selected.                                     |
| [Switch](/native/components/nativewind/switch)                                   | An on/off control.                                                             |
| [Avatar](/native/components/nativewind/avatar)                                   | A round picture with a fallback.                                               |
| [Badge](/native/components/nativewind/badge)                                     | A small pill for a status or a count.                                          |
| [Card](/native/components/nativewind/card)                                       | A surface that groups related content.                                         |
| [Progress](/native/components/nativewind/progress)                               | A bar showing how far a task has got.                                          |
| [Spinner](/native/components/nativewind/spinner)                                 | A circle that turns while something loads.                                     |
| [Unsaved changes toolbar](/native/components/nativewind/unsaved-changes-toolbar) | A floating bar with Reset and Save while a form has unsaved changes.           |
| [Separator](/native/components/nativewind/separator)                             | A rule between groups of content.                                              |
| [Skeleton](/native/components/nativewind/skeleton)                               | A placeholder block for loading content.                                       |
| [Tabs](/native/components/nativewind/tabs)                                       | Panels switched by a row of triggers.                                          |
| [Tab bar](/native/components/nativewind/tab-bar)                                 | A bar of top-level destinations at one edge of the screen.                     |

Each component also installs `utils`, which gives it `cn`.
