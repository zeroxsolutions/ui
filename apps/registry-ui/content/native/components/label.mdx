## Installation

<InstallCommand name="label" />

The CLI writes `components/ui/label.tsx`, installs [Text](/native/components/nativewind/text) and Utils, and adds
`@rn-primitives/label`.

## Usage

```tsx
import { useRef } from 'react';
import type { TextInput } from 'react-native';

import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
```

```tsx
const input = useRef<TextInput>(null);

<Label nativeID="email-label" onPress={() => input.current?.focus()}>
  Email
</Label>
<Input ref={input} aria-label="Email" aria-labelledby="email-label" />
```

React Native has no link between a label and its field. On Android a field takes the label's text as its name
when its `aria-labelledby` holds the label's `nativeID`. iOS ignores `aria-labelledby`, so give the field the
same name in `aria-label` as well. Pressing a Label runs only its `onPress`, so point that at the field's
`focus()`.

## API reference

### Label

Takes every prop of the `@rn-primitives/label` root, plus:

| Prop       | Type        | Default  |
| ---------- | ----------- | -------- |
| `children` | `ReactNode` | required |
| `nativeID` | `string`    | none     |
| `disabled` | `boolean`   | `false`  |

`disabled` dims the label to match a disabled field. It does not block presses.
