## Installation

<InstallCommand name="spinner" />

The CLI writes `components/ui/spinner.tsx`, installs [Icon](/native/components/nativewind/icon) and Utils, and adds
`lucide-react-native`.

## Usage

```tsx
import { Spinner } from '@/components/ui/spinner';
```

```tsx
<Spinner aria-label="Saving" />
```

## API reference

### Spinner

Takes every prop of [Icon](/native/components/nativewind/icon) except `as`, plus:

| Prop         | Type     | Default     |
| ------------ | -------- | ----------- |
| `aria-label` | `string` | `'Loading'` |

It is announced as a busy progress bar named by `aria-label`. `className` styles the icon, which is 16px by
default. Inside a [Button](/native/components/nativewind/button) it takes the button's label colour.

It stands still while the system's reduce motion setting is on, and while that setting is being read.
