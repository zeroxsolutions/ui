## Installation

<InstallCommand name="skeleton" />

The CLI writes `components/ui/skeleton.tsx` and installs Utils. The file is the engine's own version, so a
NativeWind app and a Uniwind app each get theirs. The Uniwind file also adds `uniwind@^1.13.0`.

## Usage

```tsx
import { Skeleton } from '@/components/ui/skeleton';
```

```tsx
<Skeleton className="h-4 w-48 rounded-md" />
```

Size it with `className`.

## API reference

### Skeleton

Takes every prop of React Native's `View`. The Uniwind file takes those of `Animated.View`.

The pulse differs by engine. The NativeWind file runs `animate-pulse` on a device. Uniwind does not run it, so
the Uniwind file fades the block to half opacity and back on a loop with `Animated`.
