---
title: Introduction
description: React Native items for iOS and Android, drawn in shadcn's Vega or Nova style, for NativeWind or Uniwind.
---

zui native publishes React Native items for iOS and Android apps, installed with the shadcn CLI like the web
items. Each item draws shadcn's Vega or Nova style with its neutral colours, and is published once per styling
engine and style:

| Engine       | Style | `style` in `components.json` | Items served from                                                    |
| ------------ | ----- | ---------------------------- | -------------------------------------------------------------------- |
| NativeWind 4 | Vega  | `nativewind-vega`            | `https://ui.zeroxsolutions.com/r/styles/nativewind-vega/<name>.json` |
| NativeWind 4 | Nova  | `nativewind-nova`            | `https://ui.zeroxsolutions.com/r/styles/nativewind-nova/<name>.json` |
| Uniwind      | Vega  | `uniwind-vega`               | `https://ui.zeroxsolutions.com/r/styles/uniwind-vega/<name>.json`    |
| Uniwind      | Nova  | `uniwind-nova`               | `https://ui.zeroxsolutions.com/r/styles/uniwind-nova/<name>.json`    |

The CLI picks the path from the app's `style`, so an app names its engine and style once, in `components.json`, as
[Installation](/native/docs/installation) shows.

## Components

[Components](/native/components/nativewind) lists every item. A component page is read under one engine, and the
NativeWind / Uniwind switch in the header moves it to the other.

These pages show no live preview, because the items render through React Native and this site does not run it.

## macOS and Windows

zui native targets iOS and Android only. A macOS or Windows app uses the [web items](/docs/components/base) through
Electron.
