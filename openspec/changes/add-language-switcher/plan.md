both kinds, built-in option data), its dependency on `@zeroxsolutions/icons`, and the editor
code-block wiring — plus tests and a story. Single serial plan, same-tree on `master`.

## Execution Strategy

tdd-preferred

## Ordered Steps

1. Add `@zeroxsolutions/icons` to `@zeroxsolutions/ui`'s `package.json` (workspace ref); `pnpm install`.
2. Author the shiki-id → Material-icon map (static imports + aliases + fallback).
3. Author `codeLanguageOptions()` and `localeOptions(codes)` builders.
4. Write the spec assertions for the controlled contract, the three forms, `kind` data, `options` override, and the `.Segmented`-has-no-`searchable` guarantee (expected to fail first).
5. Implement `language-switcher.tsx`: the shared controlled core + `.Dropdown` (dropdown-menu ↔ combobox on `searchable`), `.Segmented` (toggle-group), `.Icon` (icon trigger); attach compound sub-components; wire keyboard + accessible names → make the spec green.
6. Swap the code-block `<input>` for `<LanguageSwitcher.Dropdown kind="code" searchable …>`, keeping attrs/codec/export unchanged; keep the code-block spec green.
7. Add the storybook story (3 forms × 2 kinds, incl. searchable code dropdown).
8. Run the full green gate + rule-audit; write the verification note.

## Validation Per Step

1. `pnpm install` resolves; a throwaway import of `@zeroxsolutions/icons/material/typescript` typechecks inside `packages/ui`.
2. Every id in `src/lib/shiki.ts` resolves to an icon or the defined fallback (unit assertion / quick script).
3. `codeLanguageOptions()` returns one entry per shiki id with an icon; `localeOptions(['en','vi','ja'])` yields native names.
4. `nx test @zeroxsolutions/ui` shows the new spec failing for the expected reasons.
5. `nx test @zeroxsolutions/ui` green; `nx typecheck @zeroxsolutions/ui` green (incl. `.Segmented` omitting `searchable`).
6. `nx test @zeroxsolutions/editor` green; code-block attr round-trip + HTML export assertions unchanged.
7. `nx build-storybook` green; the story renders all six form×kind cells.
8. `nx typecheck/build/test @zeroxsolutions/ui @zeroxsolutions/editor` + `build-storybook` all green; rule-audit clean.
