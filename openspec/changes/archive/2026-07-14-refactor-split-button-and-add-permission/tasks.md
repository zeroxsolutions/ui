- [x] 1.1 Rewrite `packages/ui/src/components/split-button.tsx` as a compound: Root composing `ButtonGroup`, plus `SplitButtonAction` (primary `Button`, `data-slot="split-button-action"`), `SplitButtonMenu` (wraps the Base UI `DropdownMenu`), `SplitButtonTrigger` (caret `Button` via `DropdownMenuTrigger render=`, `data-slot="split-button-trigger"`), `SplitButtonContent`, `SplitButtonItem` - primary and trigger stay adjacent group siblings so the seam selectors apply.
